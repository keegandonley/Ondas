# Trademark and project-identity policy

"Ondas" and the Ondas logo are used to identify the upstream project. This policy does
not claim that either is registered as a trademark in every jurisdiction; it explains
how to use the project's identity without confusing users.

The [GPL-3.0 license](LICENSE) grants copyright permissions for the source code. It
does not grant permission to imply that a modified version is made by, endorsed by, or
supported by the upstream Ondas project.

## Permitted use

You may use the name truthfully to refer to this project, for example:

- "Ondas is licensed under GPL-3.0."
- "Example App is a fork of Ondas."

You may distribute an unmodified build as Ondas when doing so accurately identifies
the upstream project and does not create a false impression of official support.

## Forks and modified builds

If you distribute a modified build, choose a distinct app name, bundle identifier,
icon, and release channel. Clearly state that it is a fork or modified version of
Ondas, identify your changes, and avoid using the Ondas logo as its primary product
icon. Do not use the name or logo in a way likely to confuse users about who publishes,
maintains, or supports the build.

For questions about a use not covered here, contact
[kd@keegandonley.com](mailto:kd@keegandonley.com) before distribution.
